# TRAIN TMS — เวอร์ชันทดลองจากงาน S

ปรับหน้าจอสำหรับการฝึกพนักงานใหม่ โดยอิงเอกสารฉบับแก้ครั้งที่ 18 คงโทนกรมท่า/ส้ม/อำพันเดิม

## เปิดในเครื่อง
ต้องใช้ Node.js 24 ขึ้นไป เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
npm --prefix backend ci
npm --prefix frontend ci
npm start
```

เปิด http://localhost:5173 และหยุดด้วย Ctrl+C
ค่าเริ่มต้นใช้ SQLite ใน `backend/database.sqlite` พร้อมข้อมูลตัวอย่าง ไม่ต้องติดตั้ง MySQL
หากต้องการ SQLite ให้เว้น DB_HOST ว่าง; การเชื่อม MySQL เป็นความสามารถเดิมที่ควรทดสอบแยกก่อนใช้จริง

## เปิดใน Codespaces
นำโค้ดนี้ขึ้น repository ทดลอง แล้วสร้าง Codespace การติดตั้ง dependencies จะทำงานจาก `.devcontainer/devcontainer.json` จากนั้นรัน `npm start` ใน Terminal และเปิดพอร์ต 5173 จากแท็บ Ports หากต้องการให้เพื่อนเปิดดู ให้ตั้ง Visibility ของพอร์ตนี้เป็น Public ขณะสาธิต เมื่อจบให้หยุด Codespace

## ขั้นตอนสาธิต
1. ผู้เรียน: ดูภาพรวม → แผนการเรียน → บทเรียนและส่งงาน แนบ URL จริงที่ผู้ฝึกสอนมีสิทธิ์เข้าดู
2. ผู้ฝึกสอน: ดูงานรอตรวจ → เปิดผลงาน → ให้คะแนนและเขียนคำแนะนำ → บันทึก
3. ผู้เรียน: ดูผลประเมิน หากผ่านให้เรียนบทถัดไป หากไม่ผ่านให้ส่งงานแก้ไข
4. HR: ดูภาพรวม บัญชี และรายงานผลฝึก 2 เดือนแรกเพื่อประกอบการพิจารณาทดลองงาน 4 เดือน

## ขอบเขตเวอร์ชันนี้
ปรับการใช้งานและการนำเสนอ ไม่ใช่การรับรองว่าระบบพร้อมใช้จริงครบทุกข้อในเอกสาร
- การส่งงานรองรับ URL ของไฟล์/ผลงาน ยังไม่มีการอัปโหลดไฟล์จริงเข้าระบบ
- ส่งออกรายงานเป็น CSV และพิมพ์/บันทึก PDF ผ่านเบราว์เซอร์ ยังไม่มี XLSX
- ข้อมูลตัวอย่างบางรายการเป็นลิงก์สมมติ ต้องเปลี่ยนเป็นสื่อและผลงานจริงก่อนสาธิตรายการนั้น
- Authentication, รหัสผ่าน, API authorization และการสำรองข้อมูลยังต้องพัฒนาต่อก่อนใช้งานจริง
- ไม่แสดงเครื่องมือ SQL หรือรหัสเอกสารบนเว็บ และไม่เปิดเส้นทาง `/api/database`
- SQLite อยู่ใน Codespace/เครื่องที่รัน backend ไม่ซิงก์ผ่าน Git อัตโนมัติ

## สิ่งที่ปรับ
จัดเมนูตามบทบาท หน้าเข้าสู่ระบบใหม่ แถบด้านข้างรองรับมือถือ ภาพรวมพร้อมงานที่ต้องทำต่อ ตารางเลื่อนบนจอแคบ เปิดบทเรียนที่เลือกหรือบทปัจจุบันก่อน ยกเลิกปุ่มสร้างผลงานสมมติ ซ่อนช่องส่งงานขณะรอตรวจ/ผ่านแล้ว และแก้คำอธิบายรายงานให้แยกช่วงฝึก 2 เดือนจากการทดลองงาน 4 เดือน

ต้นฉบับ ZIP ของ S เก็บไว้แยกต่างหาก ไม่รวม node_modules ในไฟล์ส่งต่อ

## ผลตรวจเวอร์ชันนี้
- Production build ผ่าน
- เปิดหน้าทั้ง 11 หน้าของ 3 บทบาทได้ ไม่มี JavaScript page errors ในการตรวจเบราว์เซอร์
- ตรวจความกว้างหน้าทั้ง 11 หน้าที่ 390px และปรับตาราง/คอลัมน์ให้ไม่ล้นหน้า
- ทดสอบบัญชี 3 บทบาทและ API อ่านข้อมูล 14 จุด
- ทดสอบส่งงาน → รอตรวจ → ประเมินผ่าน → ปลดล็อกบทถัดไป โดยใช้ฐานข้อมูลแยกสำหรับทดสอบ
- ตรวจว่า API เครื่องมือ SQL ตอบ 404
- ยังไม่ได้ทดสอบสร้าง Codespace จริง หรือเชื่อม MySQL ภายนอก
